> yuko-ono

`yuko-ono` is the entrant's own handle (https://make.fun/u/yuko-ono): a real make.fun username, short and warm, two beats with the "o" sounds echoing each other — a name its owner happily wears, with no spaces, no padding and no gloss tacked on.

## Run it

```sh
node main.ts
```

Run it with Node 22+. The output is deterministic: every run writes the same single word, byte for byte (8 characters, 8 bytes, no trailing newline).
